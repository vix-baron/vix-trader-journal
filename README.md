# VIX Trader Journal

## About
VIX Trader Journal is a web-based trading journal
designed to help traders record their trades and
analyse their trading performance.

## Current Features
- Dashboard overview
- Account balance display
- Trading performance statistics
- Maximum drawdown display
- Recent trades section

## Technologies
- HTML

## Project Goal
To build a platform that helps traders review their
trading history, understand their performance, and
identify areas for improvement.

## Development Status

- Currently building the project step by step.
- HTML structure completed; CSS and JavaScript are planned next.
